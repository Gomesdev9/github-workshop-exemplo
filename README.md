# github-workshop-exemplo

Repositório de prática da aula de GitHub — fluxo de trabalho em equipe.

## Objetivo
Praticar branches, Pull Requests, resolução de conflitos e um workflow
básico de GitHub Actions.

## Como participar
1. Faça um fork deste repositório
2. Clone o seu fork localmente
3. Siga o roteiro passado em aula (branch → commit → push → PR)
