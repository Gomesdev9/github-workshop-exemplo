Sobre este projeto

Esta página foi criada como base de estudo: HTML puro, CSS customizado e o framework Bootstrap para componentes prontos e responsividade. Use-a para praticar Git — crie um repositório, faça commits, abra branches, teste pull requests e sinta-se à vontade para editar tudo.
